## AI日报（ai-daily cron）运行 + 博客推送修复

流程：`scripts/daily-news.sh` → MiniMax 搜索 → `scripts/build_blog.py` 生成文章并同步首页/归档/标签 → 推 GitHub gh-pages → 飞书推送。今日 10 条新闻，页面已上线（200）：
https://chu-jue.github.io/ai-news-blog/2026/10/23/2026-10-23-ai-news/

### 根因：git push 一直被拒
- `ai-news-blog-source` 的 remote URL 里内嵌了 PAT（与 .github_token 同一个），但每次走 REST API 兜底会
  在远端产生**多个 commit**，本地 git 分支落后 → 第二天 `git push` 报
  "rejected (fetch first)"，于是又走兜底，形成「远端越堆越乱」的循环。
- 修复：
  1. remote URL 改成不带 token 的 `https://github.com/chu-jue/ai-news-blog.git`，
     用 `credential.helper store --file=/root/.openclaw/workspace/.git-credentials` 取凭证。
  2. `scripts/daily-news.sh` 推送前 `git fetch + reset --hard origin/gh-pages` 对齐，
     兜底后再 fetch+reset 一次，保证明天 git push 能走通。
- 顺手把主仓库 news-daily 的 remote 改成无 token + credential helper，之前
  `fatal: Authentication failed` 也是这个原因。

### 遗留
- `dailynews` 子模块一直 dirty（README.md 改动 + 未跟踪 news.json），未处理。
- cron `daily-news`(68bfc3e8) 连续 221 次 error：agentTurn 会话超时 600s。
  实际 news-collector.sh 只要 3.5s 就跑完，超时可能是会话本身的问题（并发两个 8:00 任务）。
